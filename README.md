# 📄 Sistema de Validação de Documentos de Empresas Parceiras

> Aplicação desenvolvida para automatizar o processo de validação e gerenciamento da documentação de empresas parceiras, proporcionando maior controle, conformidade e agilidade nos processos de homologação.

Este projeto faz parte do meu portfólio de desenvolvimento de software e demonstra a aplicação de conceitos de desenvolvimento web, banco de dados e gestão documental voltados ao ambiente corporativo.

---

# 📋 Sobre o Projeto

O **Sistema de Validação de Documentos de Empresas Parceiras** tem como objetivo centralizar o controle da documentação exigida para empresas terceirizadas e fornecedores, permitindo acompanhar a situação de cada documento, identificar pendências e garantir maior conformidade com os requisitos internos.

A solução busca reduzir processos manuais, minimizar erros e facilitar auditorias, promovendo maior eficiência na gestão documental.

---

# 🎯 Objetivos

* Centralizar a documentação de empresas parceiras
* Controlar a validade de documentos obrigatórios
* Facilitar o acompanhamento de pendências
* Reduzir processos manuais
* Melhorar a conformidade documental
* Apoiar auditorias internas
* Garantir maior rastreabilidade das informações

---

# ✨ Funcionalidades

* Cadastro de empresas parceiras
* Upload e gerenciamento de documentos
* Consulta e pesquisa de registros
* Controle da validade dos documentos
* Atualização e exclusão de cadastros
* Identificação de documentos pendentes
* Organização por empresa e categoria documental
* Interface intuitiva para gerenciamento

# ⚙️ Como Executar

## Clone o repositório

```bash
git clone https://github.com/Daniel010203/Projeto-de-sistema-para-valida-o-de-documentos-de-empresas-parceiras.git
```

## Acesse a pasta

```bash
cd Projeto-de-sistema-para-valida-o-de-documentos-de-empresas-parceiras
```

## Configure o ambiente

Caso utilize o XAMPP:

* Inicie o Apache
* Inicie o MySQL
* Copie o projeto para a pasta **htdocs**

## Banco de Dados

Crie um banco MySQL e importe o arquivo `.sql` disponibilizado no projeto (quando disponível).

## Execute

```text
http://localhost/Projeto-de-sistema-para-valida-o-de-documentos-de-empresas-parceiras
```
